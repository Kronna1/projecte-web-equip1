# projecte-web-equip1

Repositori de pràctica per al treball col·laboratiu basat en branques i pull requests.
Desenvolupat per [Alexandra A](https://github.com/Kronna1), [Fran G](https://github.com/franguardia1) i [Paula M](https://github.com/paulamerizalde-spec), membres del grup 1.

Corresponent a l'exercici "Introducció a l'ús de github com a eina per a desenvolupar en equip" del mòdul d'Optativa de CFGS DAW1 que té la finalitat d'implementar l'ús d'eines de control de versions mitjançant repositoris locals Git i repositoris remots a la plataforma GitHub.

Per aquesta s'havia de crear un lloc web de temàtica centrada en algun event cultural de proximitat.

En el nostre cas s'ha escollit realitzar-la al voltant del festival [*Monegros Desert Festival*](https://monegrosfestival.com/es), un festival de música electrònica que té lloc al Desert dels Monegros, a la Província d'Osca.

# Disclaimer:
Aquest és el resultat d'un exercici acadèmic. No tenim relació alguna amb el festival. Tots els drets reservats als creadors del festival Monegros Desert Festival.

# Continguts del repositori:

+ Estructura HTML general i secció de contacte (Alexandra A.)
+ Estils CSS i layout responsive (Paula M.)
+ Funcionalitats JavaScript com un slider d’imatges i validació de formulari (Fran G.)

# Flux de treball:
+ El repositori compta amb 3 branques: html-estructura, css-estils i js-funcions
+ El treball es realitza localment actualitzant el codi al repositori remot mitjançant l'execució de comandes git al terminal.
+ Al final de cada sessió de treball s'ha realitzat un commit a la branca corresponent i una Pull Request per integrar els canvis sobre la branca principal, (main).
+ La resta de membres revisen i aproven els canvis o en suggereixen millores
+ Finalment es fa merge al main i es comprova la integració.
